# Commercial license -- placeholder, not binding

This file exists so nobody mistakes silence for terms.

**No commercial license text exists yet.** This project's core (`src/horizon_memory/`) is
licensed `AGPL-3.0-or-later`, exactly as documented in the repository root's
[`LICENSE_POLICY.md`](../LICENSE_POLICY.md). That policy already anticipates this moment:

> Separate commercial licenses may be offered later, but they do not revoke rights already
> received under an open-source release.

That is the whole plan so far: a free, AGPL core (the same model Linux distributions are built
on), and a commercial license offered separately to customers who want to redistribute or run
this without AGPL's own obligations (most notably, the requirement to offer corresponding
source to users interacting with a modified version over a network).

**What this file is not**: it is not a contract, not a price list, not a set of binding terms.
Nothing in this repository invents commercial licensing language -- that needs real legal review
before it is offered to anyone. Until a real commercial license exists and is explicitly granted
in writing, every file in this repository is governed only by the license its own header states
(AGPL-3.0-or-later by default, `Apache-2.0 OR AGPL-3.0-or-later` for files under
`src/horizon_memory/adapters/` that say so).
