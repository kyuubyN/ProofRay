# Contributors

This is the project's roster, broader than `AUTHORS.md` (which is scoped to
authorship for scientific citation). Everyone listed in `AUTHORS.md` is a
contributor here too; this file also has room for contributions that don't
rise to co-authorship (documentation, testing, tooling, review) as the
project grows past its private alpha. See `CONTRIBUTING.md` for the policy
that will govern accepting new contributions.
